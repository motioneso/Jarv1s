# @jarv1s/ui option vocabulary

Generated by `pnpm build:ui-catalogue` from each component's own exported types — do not
hand-edit. A prop appears here only if its type is a string-literal union (an `options` entry,
with its legal values) or a plain `boolean` (a `flags` entry). This is the authoritative list
of every variant/size/tone/etc. string a component currently accepts; do not invent a value
that isn't listed here, and do not add a raw `jds-*` class as a substitute for one — extend the
component's union type in `packages/ui/src/` instead. See `packages/ui/catalogue.json` for the
machine-readable form (also carries each component's file path and exports).

## avatar

- **size** (optional): `xs`, `sm`, `md`, `lg`
- **square** (optional boolean flag)

## badge

- **tone** (optional, default `neutral`): `neutral`, `forest`, `amber`, `red`, `steel`, `solid-pine`, `solid-amber`
- **outline** (optional boolean flag)
- **pill** (optional boolean flag)
- **dot** (optional boolean flag)

## button

- **variant** (optional, default `primary`): `primary`, `secondary`, `quiet`, `accentSoft`, `danger`
- **size** (optional, default `md`): `sm`, `md`, `lg`
- **block** (optional boolean flag)

## card

- **padding** (optional): `sm`, `md`, `lg`
- **sunken** (optional boolean flag)
- **flush** (optional boolean flag)
- **raised** (optional boolean flag)
- **interactive** (optional boolean flag)

## chip

- **toggle** (optional boolean flag)
- **selected** (optional boolean flag)

## dialog

_No enum or boolean props._

## divider

- **orientation** (optional, default `horizontal`): `horizontal`, `vertical`
- **weight** (optional, default `default`): `default`, `strong`, `ink`

## icon-button

- **variant** (optional, default `default`): `default`, `secondary`
- **size** (optional, default `md`): `sm`, `md`, `lg`
- **active** (optional boolean flag)

## indicator

- **status** (required): `ready`, `drift`, `error`, `idle`
- **live** (optional boolean flag)

## segmented

_No enum or boolean props._

## select

_No enum or boolean props._

## switch

- **checked** (required boolean flag)
