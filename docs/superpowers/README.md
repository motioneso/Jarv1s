# docs/superpowers — dated records

**2026-08-06 — product renamed to Moss.** Issue #1441 (part of epic #1440) renamed the product
from Jarvis/Jarv1s to Moss.

Documents below this directory (`docs/superpowers/plans/`, `docs/superpowers/specs/`, and
everything else under `docs/superpowers/`) are dated records of decisions made at the time they
were written, and use the former name throughout — deliberately, and left verbatim. They are not
rewritten when the product is renamed; treat the name used in each document as accurate for that
document's date, not as the current product name.

The rename design spec itself,
[`specs/2026-08-05-moss-rename-design.md`](specs/2026-08-05-moss-rename-design.md), is a partial
exception: written under the old name's repository, it is the record of the change and keeps both
names deliberately (see its §6).

For the current product name and status, see the root [`README.md`](../../README.md) and
[`CLAUDE.md`](../../CLAUDE.md).
